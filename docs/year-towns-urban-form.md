# 年份群岛城市形态（旧港城 / 星港城）

本文件是年份群岛两座大城「怎么长成一座城」的设计依据，与
`docs/year-towns-design.md` §3/§7 配套。设计文档讲数据边界与分层，
本文讲城市形态本身：海岸、地形、街网、街区、建筑落位。

## 问题

当前形态有三个硬伤，全部来自「没有先定城市，再定建筑」：

1. **岛是圆盘**。`IslandShapeMod` 只用 2–3 阶谐波微调半径（±15%），
   看上去仍是正圆，没有半岛、海湾、岬角、离岸小屿。
2. **街网是三条直线**。港前大道 + 两条横街拼成「十」字，没有街廓，
   没有主次层级，没有广场作为空间节点。
3. **建筑是网格填满**。2024–2026 的 40 栋建筑落在 7×6 的整数格上，
   间距恒为 6.0/7.0，没有连续街墙，没有院落，没有空地节奏。

## 决定

### 1. 岛形：显式海岸线，而不是径向谐波

`IslandOutline` 用「(dx, dz, 平滑度) 控制点」逐点描述海岸，Catmull-Rom
闭合成曲线，再按 1.2u 重采样。控制点手写，因此可以直接画出：

- 北侧长岬伸向航道（星港城），西南侧内湾（旧港城避风澳）；
- 两处小海湾把海岸切进去，形成码头的水面凹口；
- 离岸一座小屿（`IslandSatellite`），与主岛之间留一条窄水道。

曲线按「弧长参数化」重采样，`rho ≤ R(θ)` 的判定与旧版一致，
所以高度场、岛体网格、沙线盘、地形审计仍然共用同一个采样器。

### 2. 地形：山脊贴海岸，城区压平

- `IslandHill` 改成沿脊线的一串高斯峰（`IslandRidge`），不是孤立的圆包；
- 城区用 `IslandTerrace` 压平，阶地形状跟随街区而不是矩形；
- 码头区单独压一小块阶地，保证栈桥根部与街面同高。

### 3. 街网：主街 + 次街 + 巷，按层级铺

`IslandStreetGrid` 从「几条无宽度差异的线」升级为：

- `avenue`（主干道，双向，带中央绿带）
- `street`（次街，两侧人行道）
- `lane`（巷道，单侧人行道，可错位）
- `plaza`（广场，节点空间，建筑围合）
- `promenade`（滨水步道，沿海岸内侧走）

街网先定，建筑落位必须引用某条街作为临街面。

### 4. 街区：街廓而不是点位

`IslandBlock` 手工登记每个街廓的矩形范围、临街边与用途
（商业 / 居住 / 公共 / 仓储），建筑按街廓分配。街廓内：

- 沿临街边成排（街墙连续，进深方向留后院）；
- 转角建筑占地更大，形成转角体量；
- 街廓中心留空地（院落 / 小广场 / 树），不铺满。

### 5. 建筑：一栋一栋写，带朝向与进深

`YearTownMemorial.layout` 增加：

- `facing`：`'n' | 's' | 'e' | 'w'`，建筑正面朝向哪条街；
- `depth`：可选，进深与宽度不同时给出（默认方体）。

`plot` 的语义改为「沿街面宽」，不再当正方形外接框用。

## 验收

- 全图视野能认出：半岛与海湾在哪、主街从车站到码头怎么走、
  哪几个街廓密、哪里是空地；
- 街景视野能看到连续街墙、转角体量、临街窗面朝向街道；
- 不存在两栋建筑间距恰好相等的规则网格。
