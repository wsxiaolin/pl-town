# 入侵 CG（Invasion CG）

「入侵」CG 复用开场 CG（「城之诞生」）的程序化 Canvas2D 引擎与影院边框（letterbox / scanlines / grain），但叙事结构不同：**它是一条贯穿约 46 秒的连续长镜头**，不像开场 CG 那样被切分为五幕。内容：和平的小城 → 天空裂口撕开 → 入侵者涌入 → 楼宇在光束中一栋接一栋地毁坏 → 人们四散奔逃 → 废墟后落下片名。

CG 全程在与开场 CG 相同的独立覆盖层（`#cgOverlay`）内渲染，不占用实际小镇的 3D 场景。

## 触发方式（仅限控制台）

CG 不接入任何界面按钮或剧情流程，只能在浏览器控制台调用：

```js
window.playInvasionCG();   // 开始播放，返回是否成功
window.stopInvasionCG();   // 立即停止并淡出
window.__mini().invasionCG(); // 与 playInvasionCG() 等价
```

播放中点击界面任意处或按 `Esc` 可退出；片名出现后约 9 秒自动退出。重复调用 `playInvasionCG()` 会干净地重启。若开场 CG 正在播放，会先终止其渲染循环再接管覆盖层。

## 深度处理（重点）

所有可绘制对象都带有一个深度因子 `d`（0 = 无穷远，1 = 主平面，>1 = 前景），三条规则共同营造出空中透视感而不是平面剪纸：

- **视差**：屏幕坐标 += `cameraShake * d`。被击中时近景晃动大、远景几乎不动，镜头冲击感立刻分出前后景。
- **缩放**：元素尺寸 × `depthScale(d) = 0.3 + 0.72d`。入侵者从裂口（深，小）飞向盘旋轨道（近，大）；前景难民波比中景难民大一号。
- **雾化（haze）**：颜色按 `hazeAmt(d) = clamp01((1-d)*0.9)` 向大气色偏移，远景自动退到烟红色雾霭后面。雾色随「和平→战争→废墟」阶段平滑过渡。

分层的画家算法顺序（后→前）：天空渐变 → 裂口(d≈0.3) → 远景天际线(d≈0.42) → 远层无人机(d≤1) → 主楼群(d=1,含锁定框/逐层崩塌) → 近层无人机(d>1) → 光束/冲击波 → 烟/碎块 → 中景难民 → 中层余烬 → 前景难民(d≈1.9) → 前景余烬(d=1.8) → 红色警戒 vignette → 横向切片 glitch。

## 战斗感元素

- 裂口撕开时的红色脉冲 vignette 与 chromatic aberration 残影；
- 无人机从裂口处带着引擎尾迹入场，红色「独眼」随深度缩放；
- 每栋楼被摧毁前约 1 秒出现红色锁定框（reticle），随后无人机光束命中、冲击波环、碎块飞溅与烟柱；
- 摄像机震动由事件驱动（`shakeEnergy` 注入并指数衰减），glitch 切片只取已合成画面做横向错位，不做整帧再采样；
- 开场 CG 的 `.cg-cut` 光扫只在开场时扫过一次，之后不再切场。

## 时间与结构

- `0–5s` 和平：黄昏渐变、星光、中/前景行人慢步；字幕逐行上。
- `5.2s` 裂口撕开；`5.6s` 起 22 架无人机持续涌入（纯时间函数，零状态）。
- `12s` 战争阶段开始：难民开始奔逃；`13.5s` 起楼群按种子顺序逐栋崩塌（约 1.5s/栋），最后两栋幸存。
- `20s / 26s` 两波前景难民横穿画面。
- `37s` 片名「入侵」揭示；`46s` 自动退出。

所有运动都由连续 `t` 驱动（GSAP 之外的无切点时间线），粒子（烟/碎块/余烬）用 `dt` 积分，崩塌、光束、难民等均通过时间阈值边沿触发，重放/重启均为确定行为。

## 无障碍

`prefers-reduced-motion` 下直接跳到片名阶段的静态废墟画面：无震动、无 glitch 切片。`destroyMiniCity()` 内会一并释放 CG 循环与监听器。
