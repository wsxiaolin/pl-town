# 年份群岛城市重造总纲（year-towns urban redesign masterplan）

> 本文档是 2026-10-31 城市重造任务的设计锚：所有布局手写、逐栋落位、以审计单测为验收。
> 主城（BUILDING_DEFS/主城街网/治理账本）一律不动；改的只有年份群岛。

## 0. 现状诊断（为什么烂）

- 三座物理岛：旧港城（2020–2023，island-oldport，圆盘 r124 @ (-5,302)）、星港城（2024–2026，island-starport，r130 @ (-285,262)）、起源村（2019，r22）。
- 街网骨架尚可（旧港 21 街 10 广场、星港 18 街 9 广场），但**登记街廓只有 7+3 块**，106 座设施被锁死在几个小块里；星港西侧一整条街 + 两个大广场零街廓。台面大部分空着，"有骨架没有肉"。
- 外城建筑 58 栋、生活道具 93、装饰 38、NPC 18——对两座 r≥124 的城市远远不够。

## 2. 八镇城市设计（逐年身份 + 街廓分配）

每一年 = 大城里的一个**年份街区**，有自己的中心（广场/地标）、临街立面、建筑排布。设施落位原则：
**正面朝街或朝广场、同街成排、拐角转角、大体量占路口、小体量填缝**。

## 3. 落位硬规则（审计即法律）

1. **街廓内**：layout (x,z) 必须落在所属岛的登记街廓矩形内（2020+ 全部设施；2019 豁免）。
2. **台面上**：islandSurfaceYAt(x,z) === district.topY（±1e-6）。街廓已全部验证平整，落在街廓内即满足；**不要超出街廓**。
3. **不压街**：到每条街中线距离 ≥ halfWidth + plot/2 − 0.05。经验值：avenue(3.4) + plot5.5 → ≥6.1；street(2.5) + plot4.6 → ≥4.8。
4. **不侵广场**：到广场中心距离 ≥ radius + plot/2 − 0.05。广场内圈是给装饰和道具的。
5. **坐标不重复**：全岛唯一（oldport / starport 各自查重即可，两岛坐标空间不重叠）。
6. **环线净距**：磁悬环线梁中心距建筑 ≥5.5u——环线沿海滩环走，街廓内通常安全；靠近海岸的街廓（B12/B15/S17）留 6u 以上海岸退距即可。
7. **邻楼避让**：与 cityNeighborhoods.ts 既有坐标保持 ≥7u。
8. **朝向**：facing 'n'|'s'|'e'|'w' = 建筑正面朝向；临街建筑面向所临的街，广场建筑面向广场，排屋与排屋对齐。

## 4. wave 3 扩编配额（后续 sub-agent）

- 外城建筑：58 → ~120（沿新街廓临街面成排填充；residential 用 dwelling/school 语汇，commercial 用 market/tavern/mall）。
- 生活道具：93 → ~200（街市摊位、长椅、货箱、遮阳篷、渔港渔船、码头吊臂、夜市灯串）。
- 装饰：38 → ~90（avenue 路灯列、广场喷泉/旗杆、海滨棕榈、渔港灯塔信号、夜里发光橱窗）。
- NPC：18 → ~28（每镇 3±1，站前/市集/码头各一）。

## 5. 地形与交通约束

- 台面默认全平（hills/ridges 为空）；**不在街廓范围内加任何山丘**；若未来加，必须同步扩 terraces 并过 yearTownBlockAudit。
- 海岸线谐波/离岸小屿暂不动（worldTerrainAudit 'islands' 组的恒海判据与间距约束敏感）。
- 交通：**不动** STATION_SEEDS / RING_LOOP_NODES / BRIDGE_WALK_NODES（10 站 id 进 smoke.spec 精确有序断言、ride spec 绑定站表）。wave 3 可加"站点周边微地形/装饰"，不改站表。
