# 集结 CG（Muster CG）

「集结」CG 是「入侵」CG（前情提要，issue #85）与开场 CG（「城之诞生」）共享引擎的续集。入侵的炮火熄灭之后，城里剩下的是一座伤痕累累却不肯散场的小城。**约 44 秒的连续长镜头**覆盖五个章节：余烬 → 参报 → 解析 → 守护 → 重燃。

与入侵 CG 一样，它是一条无切点时间线，不换场景、不重建 DOM，在共享的 `#cgOverlay` 里由单个 canvas 一帧一帧地渲染。调色板从冷灰烬一路过渡到黎明暖色，楼群、行人、粒子都带着深度因子 `d`。

## 触发方式（仅限控制台）

CG 不接入任何界面按钮或剧情流程，只能在浏览器控制台调用：

```js
window._mini.cinematics.startMuster();   // 开始播放，返回是否成功
window._mini.cinematics.stopMuster();    // 立即停止并淡出
```

播放中点击界面任意处或按 `Esc` 可退出；约 44 秒后自动退出。重复调用 `startMuster()` 会干净地重启。若其他 CG 正在播放，会先终止其渲染循环再接管覆盖层。

## 章节叙事（连续结构，非切幕）

- **0–4s 余烬**：冷灰色调，灰烬里浮起细小的暖色尘埃，破碎的楼群剪影。
- **4–12s 参报**：寻常居民从四面聚拢到众议院、参议院与社区中心，三栋建筑逐一亮起预热灯笼（先于黎明被打破）。
- **12–18s 解析**：各学院与技术半区的检修小组围成一圈，呼吸中的六边形扫描环、扫线、攀爬的二进制码。
- **18–24s 守护**：志愿者巡逻登场，提灯扫过黑暗的街道。
- **24–33s 重燃**：幸存的楼宇按种序逐栋点亮；最先回归的仍是那三栋公众议事厅。
- **33–44s 收尾**：标题「集结（既寿永昌）」落下，进度条到达终点后自动退出。

## 深度处理（与入侵 CG 一致的空中透视）

所有可绘制对象都带着深度因子 `d`（0 = 无穷远，1 = 主平面，>1 = 前景），三条规则共同营造空中透视感而不是平面剪纸：

- **视差**：屏幕坐标 += `cameraShake * d`。不过集结 CG 中不使用入侵 CG 那样的摄像机震动；`d` 仅决定已经预先排序的分层绘制顺序。
- **缩放**：元素尺寸 × `depthScale(d) = 0.3 + 0.72d`。巡逻者（1.6–2.1d）比市民（0.9–1.4d）大一圈；远程天际线（0.42d）压在天际线主平面（1d）后面远去。
- **雾化（haze）**：颜色按 `hazeAmt(d) = clamp01((1-d)*0.8)` 向大气色偏移，远景自动退到远处蒙蒙的雾后面。雾色随「冷烬→黎明」阶段平滑过渡。

分层的画家算法顺序（后→前）：星空 → 远景天际线 → 暖色尘埃 → 主楼群 → 技术人员 → 市民 → 巡逻 → 前景尘埃 → 修复火花 → 黎明 vignette。

## 角色分层（谁是楼里谁）

Person 的剪影分为 `walker` / `speaker` / `listener` / `patrol` / `guard` / `tech` / `comforter`。目前只区分两种剪影：

- **普通剪影**（walker/guard/comforter 等）：寻常居民彼此聚拢，或只是走过街道。
- **巡逻剪影（patrol）**：在提灯位置叠加一层发光圆形，扫过地面。

技术人员（`tech`）不画在主平面，而是围绕自己的六边形环按自己组里的 `group` 半径行走，双臂交替挥动工具，并在工具挥下时有淡蓝色的工具轨迹。

一栋建筑可以标记为 `civic`（1=众议院，2=参议院，3=社区中心）。这些选中的建筑在 `tw.litAt` 被提前到 `RELIGHT_AT - 3 + civic * 1.6`，因此我们视觉上先看到「公众议事厅先点亮、其余街道再到」。同时在黎明前的参报阶段 `pal.petition > 0`，它们会亮起预热灯笼。

## 无障碍

`prefers-reduced-motion` 下 CG 会直接从标题阶段开始（`t0 = TITLE_AT`）。`destroyMiniCity()` 内会一并释放 CG 循环与监听器。

## 连续性原则（这条 CG 与开场 CG 最大的不同）

开场 CG（「城之诞生」）把 5 幕当作 5 个独立场景，GSAP 每一幕重新构建 DOM。集结 CG 与入侵 CG 一样，只有**一条时间线**：`PETITION_AT` 等阈值很简单，但调色板、分层绘制、深度因子都是随 `t` 平滑插值的函数，所以视觉流是从灰烬缓慢「解冻」到黎明，而不是一节一节断开。
