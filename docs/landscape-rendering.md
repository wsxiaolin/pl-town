# 草地与海面渲染

草地由原有地面纹理和四批 `InstancedMesh` 草叶组成，不增加资源下载。
普通桌面每块最多 10,000 片草叶，移动端或减少动态效果模式为 2,400；
分辨率倍率不超过 0.75 时不生成草叶。草叶避开广场、环路、沙滩、建筑
地块和运行时生成的住宅地块。距离相机 35–85 世界单位时逐渐收起，
根部位于地面上方 0.012，避免远景共面闪烁。减少动态效果模式冻结草叶风动。
材质与几何由 `ResourcePool` 释放，实例缓冲在城市销毁时单独释放。

海面复用项目已有的 Three.js `Water` 和 `waternormals.jpg`，参考
[Three.js 官方水面示例](https://threejs.org/examples/?q=water)。
海面叠加两组缓慢涌浪的法线变化及低对比度浪峰光照，保留不透明海水、
镜面反射和深浅水过渡；海岸细分条带在浪头推进时显示断续泡沫，夜间随
日照变暗。海面保持平面以兼容镜面裁剪，不改变岸线、碰撞或治理布局。
关闭水面渲染时沿用原有静态水面。

`landscape-rendering.spec.ts` 检查桌面/移动端近景、海岸与远景的渲染、
控制台错误、上下文丢失、横向溢出和节能降级。截图仍需人工检查色彩、
地块间距与闪烁；帧数检查不等同于帧率基准测试。
