# 物实小城新玩家指南

这份指南写给第一次来到物实小城（MiniCity）的居民：从打开网页到安家落户，每一步该做什么、该去哪里找。读完大约需要 5 分钟。

小城是物理实验室社区的 3D 网页世界。你在城里走路、看报、听歌、串门、聊天，一切进度都跟随你的居民身份保存。游戏内的新手引导卡片与本指南内容一一对应——如果你把引导跳过了，读这份文档就能补回来。

> 想重新看一次新手引导？在浏览器控制台输入 `window._mini.tutorial.start()` 即可。

## 0. 打开小城之前

| 事项 | 建议 |
|------|------|
| 浏览器 | Chrome / Edge / Safari 最新版（需要 WebGL 2） |
| 设备 | 手机请横屏使用；竖屏会看到横屏提示 |
| 网络 | 首次进入会下载高清贴图，之后有本地缓存 |
| 本地运行 | `npm install && npm run dev`，前端 `http://localhost:5173`，服务端 `http://localhost:8787` |

首次进入时，开屏 CG「城之诞生」会讲述小城的由来。看完后需要签下昵称与密码——这是你在城里的唯一居民身份，请记牢。

## 1. 认识界面

```text
┌──────────────────────────────────────────────┐
│ ● 物实小城      地图  齿轮(画质)   城市时间   │  顶栏
│                                              │
│              3D 城市（点击探索）              │
│                                              │
│ (方向盘)                        📱 居民手机  │  手机端/右下角
└──────────────────────────────────────────────┘
```

- **城市时间**：现实 1 分钟 = 小城 1 小时。清晨、白天、夜晚会自然交替，天气（晴/雨/雪）由服务端统一下发。
- **居民手机**（右下角）：公聊、住宅、背包都收在里面，后面细讲。
- **画质齿轮**：节能 / 均衡 / 高清 / 极致 四档，随时可切换。

## 2. 先学会走路

| 操作方式 | 说明 |
|----------|------|
| 点击道路 | 角色沿路网自动走到点击处 |
| 键盘 | `W A S D` 或方向键直接移动 |
| 触屏 | 按住屏幕拖动，唤出方向盘（松手即停） |

想看全城？点顶栏**「地图」**打开全景地图：搜索框支持按建筑名称、编号模糊搜索；点击地图上的建筑即可**传送**。传送需要先累计步行 100 米解锁——认真散步本身就是新手任务。

## 3. 城里有什么可玩

每栋建筑都可以点击，弹出它的介绍卡片：

- **报摊** —— 收藏《星辉周刊》等社区刊物档案，可以逐期翻阅。
- **物实学院 / 文化馆** —— 陈列社区居民的作品与公共档案。
- **音乐厅** —— 循环播放点歌与歌词。
- **纪念碑** —— 铭记为小城付出过的人。
- **更多** —— 图书馆、档案馆、研究院、电视塔、电影城……以及一些只有走到跟前才会发现的角落。

走近 NPC 会触发对话，部分对话带选项，能接支线任务或触发传送。**建筑上方的悬浮标签**会显示它的名字，找不到路就先看标签。

## 4. 居民手机与安家

打开右下角的手机，有三个板块：

- **公聊**：与全镇居民实时连线（WebSocket 同步）。
- **住宅**：认领一间属于你的小屋，装饰与状态保存在服务端；朋友可以来串门。
- **背包**：查看物实币与收集到的物品。

物实币通过探索、成就与活动获得；成就与解锁进度跟随你的居民身份保存，换设备登录也不丢。

## 5. 隐藏内容与剧情

小城有不少需要主动发现的内容：隐藏 CG（如兰屿前置 CG、集结 CG、入侵 CG）、冰王（King Ice）剧情线、以及入侵后城市重燃的长镜头。它们大多由特定地点、特定行为或剧情推进触发——多走多点，别急。

管理员可以通过服务端天气接口改变全镇天气；入侵等事件也可能由社区活动统一触发。

## 6. 画面卡顿怎么办

1. 顶栏齿轮 → 切到 **节能** 或 **均衡**（手机推荐均衡）。
2. 关闭实时阴影、降低分辨率倍率（设置面板内）。
3. 首次加载慢通常是贴图下载，第二次进入会快很多。
4. 仍然卡顿？清一次浏览器缓存，或换桌面端浏览器。

## 7. 常见问题

**Q：忘记密码怎么办？**
身份用于标识进度，密码错误时用原昵称重签即可恢复本地进度；如仍无法进入，联系社区管理员。

**Q：竖屏提示一直出现？**
手机请横屏；浏览器全屏按钮在提示页上也有提供。

**Q：数据存在哪里？**
本地进度在浏览器 localStorage；登录后的住宅、聊天与服务端数据保存在 SQLite（部署文档见 `docs/deployment.md`）。

**Q：想本地跑一个自己的小城？**
见仓库根目录 `README.md`：`npm install && npm run dev`。

**Q：我是开发者，想调戏城市？**
控制台调试 API 见 [console-debug-api.md](console-debug-api.md)，包括天气、建筑破坏/恢复、CG 触发等。
