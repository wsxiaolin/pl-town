# 城市建设策略与历史迁移

## 新城的可用入口

治理配置 `2026-09-26.pending.2` 中，全新城市仅中心众议院（`commons`）初始建成。包括外环众议院（`commons_outer`）在内的其余命名建筑须完成筹建；未建成建筑的模型、地皮、名称、地图入口和点击入口同步隐藏。个人默认解锁与管理员访问覆盖都不能代替城市建设完成状态。

居民可通过中心众议院参与共同募捐。打开治理面板不需要先付费解锁或参观众议院：治理入口先于建筑参观流程处理。顶栏「档案」仍可打开统计与成就面板，统计面板提供纪念碑入口；这些界面入口不要求 `stats` 或 `elevator` 实体建筑建成，也不会把这两栋建筑提前建成。

其他建筑对应的剧情、商店和体验在建成后开放。`archive`、`newsstand`、`guesthouse`、`mall_south`、`mall_west` 和 `research` 是有意设置为筹建后开放的剧情入口，必须通过众议院完成相应建设项目。`litreview`、`teahouse_outer` 原有的剧情或访问限制仍然生效；建成不等同于取消所有访问条件。

## 保持原有经济规则

每位新居民有 1,200 金币，公共建筑每项需要 3,000 金币。没有其他支出时，三位居民可分别捐献 1,200、1,200、600 金币完成首栋建筑。现有每日、一次性与可重复领取奖励提供物品，没有可反复领取的金币来源。

道路与绿化中的公共工程价格较低，新居民可独自完成部分项目，例如 300 金币的绿道座椅或 450 金币的东北角路灯。治理列表提供分类跳转，可直接查看这些项目；“单人无法建成首栋公共建筑”不意味着无法参与建设或完成公共工程。

成就达成时，客户端的进度控制器自动发出成就同步，服务端校验可验证条件并通过奖励记录保证只发放一次；居民无需打开统计或成就面板、点击领取按钮。可验证的金币成就包括落籍、首次访问建筑、访问 5/10 栋建筑和解锁 3 栋建筑。仅由客户端声明、服务端无法验证的成就不会凭奖励目录中的数字发放金币。相关实现见 `apps/web/src/city/progression/progressionController.ts`、`apps/web/src/adapters/ui/cloudProgressionController.ts`、`apps/server/src/progression.ts` 和 `apps/server/src/db.ts`。

单个新居民在没有额外金币来源时仍不能独自建成首栋公共建筑。建筑访问前置的支线、剧情和相关成就需要共同募捐后开放。本次不加入首栋折扣或启动补助，维持“仅中心众议院初始建成”和现有持久化价格协议；单人兜底属于后续独立经济设计。未来若修改已持久化的建设价格或配置，须另行提供显式对账迁移。

## 历史城市的显式对账

升级和备份恢复共用事务内迁移：读取旧配置、计算保留建筑和后续写入属于同一事务，任一步失败会回滚整个迁移或恢复。旧配置的初始建筑转换为已完成项目；旧项目的 ID、定义、已筹资金额、个人装饰、居民余额和 `city_operations` 幂等记录保持不变。

只有治理账本出现前的已有居民数据库才使用冻结的 `LEGACY_INITIAL_BUILDINGS` 历史初始清单，并从 `LEGACY_UNLOCK_PRESERVATION_BUILDINGS` 许可清单读取旧解锁。许可清单内曾被居民解锁的建筑有意保留为公共已建成项目，不扣款、不生成虚构捐款记录。空数据库使用新城初始策略；已有治理账本的版本升级不再把个人解锁或管理员访问覆盖换算成建设进度，未来新增建筑也不能沿用这次兼容规则。此过程不要求 Schema 5 备份包含 `world_config` 表。

`.pending.2` 将先前遗漏的照相馆（`photostudio`）纳入服务端目录。兼容规则固定针对这个建筑 ID：保存的旧配置缺少照相馆项目、且旧账本没有该项目行时，保留其原本可见的照相馆并显式补为已建项目。判断依据是保存的配置与账本，而非版本名称清单。治理账本出现前的已有城市也保留照相馆，新城市则需要筹建。此例外不能为未来新增建筑自动赠送建设进度。

覆盖的历史配置包括 `2026-09-19.1` 和 `2026-09-25.areas.1`；`2026-09-25.pending.1` 仅在本开发分支中出现、尚未发布，对它的恢复测试是防御性兼容。照相馆对账不扣金币、不改旧项目、不新增支付收据。迁移实现位于 `apps/server/src/cityGovernanceMigration.ts` 和 `apps/server/src/cityGovernanceSchema.ts`；新城、历史配置、Schema 5 恢复和事务回滚由 `apps/server/tests/city-governance.mjs` 覆盖，常规集成套件还在准备旧城前验证新城图书馆访问被拒绝。
