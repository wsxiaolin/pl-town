# 剧情1 支线设计原稿：《今晚别走那条街》

> 改编自果戈里短篇小说《外套》（Шинель），公版作品。

---

## 一、设计动机

原作讲述低级文书阿卡基为一件新外套省吃俭用，却在回家途中被抢，向所有人求助却被推来推去，最终病逝。故事的核心不是外套本身，而是**一个被城市忽略的人如何在制度性冷漠中消失**。

pl-town 是一座俯视角小城，建筑可走可看，但室内不需进入。这个限制恰好适合《外套》——几乎所有关键事件都能放在街道、桥边、市场门口和路灯下。

### 为什么选这个故事

1. **不被一眼猜中**：不像《麦琪的礼物》那样家喻户晓，玩家对结局有期待空间。
2. **技术适配**：所有事件在街道发生，不需要室内场景、战斗系统或复杂动画。
3. **支线感强**：玩家没有拯救世界，只是试图让一件外套、一个名字和一桩普通案件，不要在城市里悄无声息地消失。
4. **与 pl-town 现有 NPC 自然衔接**：茶馆掌柜、夜行者、修路工、图书管理员、社区守望者——这些角色天然就是街头的目击者。

## 二、故事结构

### 三幕式

| 幕 | 标题 | 时长 | 核心事件 |
|----|------|------|----------|
| 第一幕 | 新外套 | 约5分钟 | 玩家在街头遇见阿卡基，陪他去茶馆门口取新外套 |
| 第二幕 | 失窃的街道 | 约3分钟 | 回家路上外套被抢，阿卡基求助无门 |
| 第三幕 | 所有人都知道，但没有人负责 | 约10分钟 | 沿街调查5位目击者，至少3人后进入结局选择 |
| 结局 | 三选一 | 约2分钟 | 找回外套 / 联名作证 / 桥上见鬼 |

### 时间线

- **白天**：认识阿卡基，陪他取外套
- **傍晚**：在街头发生抢劫
- **夜晚**：沿街询问目击者
- **深夜**：决定是否继续追查
- **次日**：通过 NPC 对话和城市公告展示后果

## 五、三结局设计

### 结局一：找回外套（ending-recover）

**触发条件**：玩家选择「去河边找那个二手衣商」

**叙事**：玩家和阿卡基在河边找到二手衣商，外套已经变了——布料被剪开重缝，纽扣换了一颗。玩家可以选择付钱买回、威胁报警、或用东西交换。

**结局文本**：
> 阿卡基接过外套，把它穿上。
> 袖口沾着泥，布料被重新缝过，纽扣换了一颗。但它还是那件外套。
> 「至少它还认得我。」
> 第二天，阿卡基还是去上班了。他穿着那件被剪开又缝上的外套，走在街上。
> 没有人注意到他。但这一次，他自己知道。

**成就**：`overcoat.recover` — "至少它还认得我"

**主题**：外套回来了，但它已经不一样了。城市的伤害是不可逆的，但至少这个人找回了一点什么。

### 结局二：联名作证（ending-witness）

**触发条件**：玩家选择「找几个人联名作证」

**叙事**：玩家带阿卡基去找阿紫（记者）。阿紫帮忙组织联名，有些人不愿开口，有些人犹豫很久，但最终有人签了名。官员终于受理案件，但只给了一张盖章的证明。第二天，公告板上多了一张新通知：「夜间街道请注意保管个人衣物。」

**结局文本**：
> 城市回应了，却只回应到这种程度。
> 阿卡基拿着那张证明，看了很久，然后把它叠好放进衣兜里——虽然衣兜里已经没有外套了。

**成就**：`overcoat.witness` — "城市回应了"

**主题**：制度性回应永远不够。城市承认了这件事发生了，但不会真正补偿。

### 结局三：桥上见鬼（ending-ghost）

**触发条件**：玩家选择「今晚再去那条街看看」

**叙事**：夜里，玩家独自回到那条街。在桥中央，看见远处有一个穿深灰色外套的人影，身形很像阿卡基。玩家可以追上去或停下来。人影消失了，地上只留下一枚骨质纽扣。第二天，听说那个傲慢的上司也被抢走了外套。城市开始流传幽灵的传闻。

**结局文本**：
> 没有人知道夜里的抢劫者是不是鬼。
> 只知道城市里那些被忽略的人，开始用同一种方式留下痕迹。

**成就**：`overcoat.ghost` — "今晚别走那条街"

**主题**：对应原作的鬼故事结尾。城市里被忽略的人开始用同一种方式留下痕迹——这是一种沉默的反抗。

## 六、设计原则

### 街道叙事

所有关键事件发生在街道：
- 取外套在茶馆门口
- 招呼在街上
- 拦劫在街角
- 询问目击者在各自站位
- 结局在河边/街头/桥上

**室内可完全省略**。裁缝、官员、商人都站在门口或街边，室内只作为背景。

### 不依赖战斗

主要冲突来自调查和选择，适合事件驱动的 RPG。没有战斗系统，没有血条，没有数值检查。

### 目击者证词互不重复

每个目击者提供不同类型的线索：
- **唐师傅** → 方向线索（河边）
- **游先生** → 外貌线索（新外套颜色）
- **老秦** → 物证（骨质纽扣）
- **林叙** → 情报链（二手衣商）
- **李叔** → 制度线索（登记表「无异常」可改）

调查 3 人即可进入结局，但 5 人全查完会获得更完整的图景。

### 选择的重量

每个结局的选择没有「好」或「坏」。玩家不需要拯救阿卡基，只需要做出一个决定：是找回那件具体的外套，还是让城市承认这件事发生过，还是在夜里去找那个也许不存在的幽灵。

## 七、技术实现

### 文件清单

| 文件 | 类型 | 说明 |
|------|------|------|
| `apps/web/src/gameplay/content/stories/overcoat/overcoatStory.ts` | 新增 | StoryDefinition，24 个节点 |
| `apps/web/src/city/data/npcs.ts` | 修改 | 新增 akaki NPC（storyOnly） |
| `apps/server/src/storyCatalog.ts` | 修改 | 新增服务端故事镜像（15 savepoint + 20 edges） |

### Story ID

```
side.overcoat.tonight
```

定义版本：1

### Flag 命名空间

```
overcoat.trust          — 玩家是否主动提出帮忙
overcoat.asked.{npc}    — 是否已询问该目击者（false=未问，true=已问）
overcoat.clue.{type}    — 获得的具体线索
overcoat.ending         — 最终结局标识
```

### Event 类型

```
overcoat.witness        — 每询问一位目击者 +1（atLeast 3 可进入结局）
```

### NPC 集成

阿卡基（`akaki`）使用 `storyOnly: true`，仅在故事进行时出现在茶馆附近路灯下。故事结束后（terminal 节点），NPC 从场景消失。

目击者使用现有 NPC（`tang`、`you`、`laoqin`、`linxu`、`li`），无需修改其现有行为或对话。调查阶段的剧情通过 story choice 驱动，不通过 NPC 世界交互——玩家在故事对话中选择去找谁。

### 服务端镜像

`storyCatalog.ts` 新增 `OVERCOAT_NODES`（15 个 savepoint 节点）和 `OVERCOAT_EDGES`（20 条边），与 `STORY_CATALOG` 一并导出，供管理后台渲染故事进度。

## 八、后续扩展方向

1. **建筑交互**：结局二可在公告板（`bulletin`）添加 buildingInteraction，让玩家走到公告板前看到那张通知。
2. **世界交互点**：在桥上添加一个 interestPoint「桥上的纽扣」，在结局三触发后可交互。
3. **NPC 调度**：阿卡基在故事结束后可设为 daytime NPC，每天在茶馆附近出现，穿那件被缝过的外套。
4. **成就联动**：三个结局成就可与 progression 系统的 UNLOCK_TIERS 联动。
5. **多周目**：二周目可增加隐藏选项——如果玩家知道上司的外套也会被抢，可以在调查阶段提前警告他。
