| 外海底 | 900×900 平面 y=−0.4，±450 |

**恒海判据（本设计自洽的基石）**：
- z > 180 ⇒ 一定在海（南缘公式最大值 180）；
- x < −150 ⇒ 一定在海（西缘公式最小值 −149.6）。
第 8 镇及以西环线均满足其一，因此**任何岛屿、轨道、桥墩都不需要逐点核对陆缘**，审计退化为两个不等式（§9）。

### 5.1 星门大桥（主城 ↔ 首镇 2019）

- 走线（桥面走廊中心线折线）：(34, 98) → (48, 118) → (66, 142) → (82, 166) → (96, 189) → 起源村·桥站北广场 (96, 197)。
  自南步道 S4 观景平台 (34,96) 南缘出发，斜跨城南草甸东南裙坡，z≈144 入海（x≈70 处南缘 z=180−18(1+sin(70/47))≈144.1），主跨海面 44u，落于起源村北滩。
- **结构 = 堤道 + 桥**：陆上段（z 98..145）为路堤（terrainHeight 新增桥面走廊场，同南步道「切槽」的正向版本：走廊内床高=桥面纵断面，两侧 4.5 融合坡；farGround 采样同一函数，路堤自然长在地上）；海上段（z 145..193）为桥（桥面 mesh + 桥墩，同一走廊高度场供导航赋 y——该处 farGround 本就无网格，零冲突）。
- 纵断面：y 1.8（S4 端）→ 3.2（冠，z 112..150）→ 1.0（岛台）。坡度 ≤5.7%；冠高满足草甸起伏 ≤3.4 + 0.5 净空。双塔（装饰，高 14）位于 (70,148)、(86,170)，斜拉索造型。
- 桥面宽 4.2：中央电车轨 1.8 + 两侧步道各 1.2；护栏/灯柱。
- 路网接线：新增桥节点 B1..B5 挂接 S4（复用 meadowTrail 工厂模式：节点表与高度场同源常量，图与地形永远一致）；WORLD_BOUNDS 随节点外扩（现状 maxZ 104 → 204+）。
- 草甸装饰避让：桥走廊权重 `bridgeCorridorWeight`（复用 trailSlotWeight 的消费模式）加入草甸散布剔除；桥墩位加 keep-out。

### 7.3 社区富文本清洗规则（生成期烘焙 + 运行时同源模块）

清洗器 `sanitizeCommunityText.ts`（纯函数，单测覆盖；gen 脚本 import 同一实现，单一事实源）：

1. 标签剥离（大小写不敏感正则）：`<color=…></color>`、`<size=…></size>`、`<b>/<i>/<u>` 及闭合 → 删标签**留内文**；`<a>…</a>`、`<a=…>` → 删标签留内文；`<discussion=ID>…</discussion>` → 删标签留内文（内文为空或纯 ID 则整段删）；`<user=ID>` → 删。
2. 平铺回复前缀：「回复<user=ID>@昵称<」→ `@昵称`（规则：先删 `<user=…>`，再把 `@短名<` 的孤悬 `<` 吃掉：`@([^\s<:：，。]{1,24})<` → `@$1`，每条一次）。
3. 未知标签 `<[a-zA-Z/][^>]{0,64}>` → 删；其余字面 `<`/`>` 保留（textContent 安全）。
4. **label-safe**（用于建筑 label/num/地图搜索键， stricter）：在 1–3 基础上再剥净残余 `<`/`>` 与控制字符，题名 ≤24 字（超长截断+…）。
5. 控制字符：删 U+200B–200D、U+FEFF、C0（\n\t 除外）；`￼`（U+FFFC）删；`\r\n`→`\n`。内部空格**不折叠**（VIP字体类作品依赖空格排版）。
6. 作者名兜底：清洗后为空/全空白字符（如 `<a>￼</a>`、`ㅤㅤㅤ`）→ 显示「无名氏」（原始名保留在数据里供检索匹配）。
7. 实测样例（by_year 数据）：`<color=lightblue>新人报道</color>` → 新人报道；`<a>月满西楼</a>` → 月满西楼；`<a>￼</a>`（作者）→ 无名氏；`<color=green>五金月饼&一瓶农夫山泉</color><a>『金月店』` → 五金月饼&一瓶农夫山泉『金月店』。

## 14. 施工修订（T3 实施后按代码现实回写；2026-10-18 T3d 补记）

设计与实现以本节为准（前文相应条目按此读）：

1. **8 岛 LOD：两级 → 单级 + 视锥剔除**（修订 §3 末条、§6.2、§12 第一行的「两级 LOD，参明澜屿」）。代码现实：明澜屿本身就是单级网格、无运行时 LOD；archipelagoIsles.ts 保持同构——每岛 2 个 mesh（岛体 `island-{year}` + 沙线盘 `{id}-sand-rim`）、各为独立 Object3D，靠 Three.js 默认逐对象视锥剔除：正交视锥窗口 ≤15u 时远镇整岛出窗即不渲染，§12「远镇出窗即剔除、零像素成本」的性能口径不变（mesh 数从 ×2 LOD 收敛为 ×2 部件）。

2. **南海片与西海条带同色拼接**（修订 §6.1 落地细节）。实现于 archipelagoWater.ts：南海片（南带东/西瓣 + 西臂）uv.x 恒 0 → vShoreDist 取条带全深 96 → **深海色**，与西海条带西缘（uv.x=0）逐像素同色；因此西臂东缘与条带西缘（shorelineX−96）按「取小对接 + ≤4u max 搭叠」防裂缝时，搭叠区同色、同层 y=0.06，观感不可见且无 z-fighting。水面仍并入**唯一** Water 实例（westBeach.ts 经 mergeWaterSheets 合并几何；waterRendering=false 的静态兜底同口径扩展），浅水 surf 渐变专属西海滩不动。数据谓词同源：sea-archipelago.ts `isArchipelagoWaterAt`（waterGuard 先岛后水）。

3. **海图页前移至 T3**（修订 §11 的 T3/T4 行分界与 §5.3「T4 对齐具体数值」）。T3a 已随地形落地：mapController 第三地区 `archipelago`、8 镇标记、`teleportToTown`（visited≥5 解锁）与图集第三页截屏。**实测口径取代 §5.3 原估值**：画框 span **190**、中心 **(−80, 150)**（8 镇滩域包络 x∈[−270,109]、z∈[45,257] 的轴对齐中心与半幅，比原写 span 195/中心 (−80,210) 更贴镇域）；contains z≥45 / clip z≥44 与主城页切线无重叠。T4 剩余：9 站点圆点、环线/星门线描线、大桥绘制与「海图·比例异于城图」页纸标注。

4. **相机 panBounds 与导航 WORLD_BOUNDS 口径**（修订 §5.1「WORLD_BOUNDS 随节点外扩」的时序）。T3 已先行为岛域外扩两套边界，**同根不同源**（都出自 data/year-towns/towns.ts，永不各写一份）：
   - 相机 panBounds = `yearTownPanBounds(CITY_LIMIT)`：主城 ±cityLimit ∪ 8 镇滩域（beachR + margin 12）轴对齐并集，传入 cameraPanController 约束**手势拖拽**平移；不传时默认 ±cityLimit，行为不变（回归安全）。
