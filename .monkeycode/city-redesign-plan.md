# MiniCity 城市重新规划方案

## 当前状况分析

当前城市有70个建筑，分布在以下区域：
- **中心城区**：围绕原点(0,0)的核心区域，包含主要公共设施
- **外环区域**：沿环路分布的外围建筑
- **北区**：星语北城扩建区（z < -36），包含住宅和文化设施
- **特殊区域**：回音天文台、西海滩等

### 现有问题
1. 建筑分布相对分散，缺乏明确的功能分区
2. 道路系统主要是网格状，缺少城市主干道和次干道的层级
3. 公共空间（广场、公园）较少
4. 居住区与商业区、文化区混杂
5. 缺少明确的城市中心和地标建筑群

## 重新规划目标

将 MiniCity 打造成一个具有真实城市特征的虚拟城市：

### 1. 城市结构
- **CBD（中央商务区）**：市中心核心区域
- **文化区**：图书馆、博物馆、剧院集群
- **教育区**：学校、学院、研究院集中区域
- **居住区**：北区和周边住宅区
- **商业区**：购物中心、市场、餐饮集群
- **滨水区**：西海滩休闲带
- **公园绿地系统**：城市绿肺

### 2. 道路系统层级
- **城市主轴**：南北中央大道 + 东西主干道
- **环路系统**：内环路（现有）+ 外环路（扩展）
- **次干道**：连接各功能区
- **街巷**：居住区内部道路

### 3. 公共空间
- **中央广场**：市中心地标广场
- **文化广场**：文化设施前广场
- **社区广场**：居住区内小广场
- **滨水公园**：西海滩沿线
- **绿地公园**：城市绿地系统

## 道路系统优化

### 主干道系统
1. **南北中央大道**（x = 0）：
   - 从中央广场向南延伸至影视城
   - 向北延伸至北区中央大道
   - 宽度：3.0 单位

2. **东西主干道**（z = 0）：
   - 贯穿东西，连接滨水区和东部新区
   - 宽度：3.0 单位

3. **环路系统**：
   - 内环：保持现有环路
   - 中环：x,z = ±21 围合
   - 外环：x,z = ±33 围合

### 次干道
- 连接各功能区的南北、东西向道路
- 宽度：2.4 单位

### 街巷
- 居住区内部道路
- 北区横街、纵巷系统
- 宽度：1.35-2.0 单位

## 公共空间体系

1. **市政广场**（0, 0 周边）：

2. **文化广场**（0, 12 周边）：

### 中期（第二阶段）

### 远期（第三阶段）

3. 景观轴线塑造

## 技术实施要点

### 建筑坐标调整
- 按功能分区重新分配建筑坐标
- 确保建筑不与道路重叠
- 保持合理间距

### 道路网络重构
- 更新 `cityConfig.ts` 中道路配置
- 调整 `ROAD_COORDS` 常量
- 增加层级化道路系统

### 公共空间创建
- 在关键位置创建开放空间
- 添加景观元素（喷泉、树木、座椅）
- 使用 `FILM_CITY_CLEARINGS` 模式创建广场

### 导航系统更新
- 更新北区 `roadNodes` 和 `roadSegments`
- 调整寻路网络
- 确保所有区域可达

## 预期效果

1. **清晰的城市结构**：中心-外环-扩展区三层结构
2. **功能分区明确**：CBD、文化区、科技区、居住区各司其职
3. **便捷的交通系统**：主干道-次干道-街巷三级体系
4. **丰富的公共空间**：广场-公园-绿地多层次开放空间
5. **鲜明的城市特色**：科技与文化融合的虚拟城市
